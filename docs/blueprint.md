# **App Name**: UniFlow

## Core Features:

- User Authentication & Profiles: Secure sign-up, login, password management, and comprehensive user profile setup, including bank account verification for name matching.
- Naira Wallet Management: Customers can deposit funds via the Monnify API, view current balance, perform secure intra-wallet payments with a personalized PIN, and receive auto-generated transaction receipts.
- Data and Airtime Services: Customers can select and purchase data and airtime packages via the Monnify API, receiving immediate confirmation and notification updates upon successful transactions.
- Food Ordering Service: Admin creates food menu cards. Customers can browse, select items, make payments, provide delivery locations, and set up recurring food subscriptions. The system initiates logistics, and customers can provide feedback and rate the service after delivery.
- Laundry Service Management: Admin creates service lists and pricing cards. Customers request approval, make payments, and provide collection/delivery locations. The system coordinates logistics for collection and delivery, with operators handling the service. Customers can provide feedback and rate the service.
- E-commerce Shop: Admin creates available item listings. Customers can select products, make payments, and provide delivery locations. The system initiates logistics for delivery, with operators delivering products. Customers can provide feedback and rate the service.
- Logistics Dispatch for Deliveries: Offers intra-state and inter-state delivery services, receiving requests from Food, Laundry, Shop, and Flexi Errand services. The system assigns operators for delivery, manages payment, and operators update delivery status in real-time.
- Crowdfunding Platform: Admin creates and manages crowdfunding campaigns or projects. Customers can contribute funds to campaigns, and the system tracks contributions and sends updates to participants.
- Investment Management: Admin sets up various investment options and rates. Customers can select investment plans, make investments, and the system manages investment tracking, payouts, and sends relevant updates.
- Flexi Errand Service: Customers can create custom errand requests (e.g., pickup, delivery). The system assigns an operator to fulfill the request, and operators update the status. Customers can provide feedback and rate the service.
- Unified Notification System: The system sends critical push notifications for updates, promotions, and offers. It also displays in-app notifications for order status, payments, and sends SMS for order confirmations and delivery updates.
- Role-Based Access Control: Manages distinct permissions and functionalities for different user roles: Customers (service usage, payments), Operators (delivery/collection tasks, status updates), and Admins (menu/service management, pricing, transaction monitoring).
- AI Content Assistant: A generative AI tool for administrators to automatically create engaging and descriptive text for food menu items, service descriptions, or shop product listings.

## Style Guidelines:

- Primary color: A modern and trustworthy blue (#1D9FD6), reflecting reliability for financial transactions and professionalism for diverse services.
- Background color: A soft, neutral off-white (#EAF2F6) for a clean and unobtrusive backdrop that enhances readability and keeps the focus on content.
- Accent color: A vibrant teal-green (#1DD1B9) to draw attention to interactive elements, calls to action, and convey a sense of efficiency and innovation.
- Body and headline font: 'Inter', a contemporary sans-serif, chosen for its excellent readability across all screen sizes and its versatile, clean aesthetic that suits both transactional and informational content.
- Utilize clean, outlined iconography with a consistent stroke weight to maintain a modern, crisp appearance. Icons should clearly represent services (e.g., food, wallet, delivery) to ensure intuitive navigation.
- Implement a modular and mobile-first layout design, prioritizing clarity and ease of use. Key information should be quickly accessible, with logical groupings for diverse services.
- Subtle, non-disruptive animations for transitions between screens, successful actions (e.g., payment confirmation), and loading states to provide positive user feedback.
